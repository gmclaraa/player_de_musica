📝 To-Do List

Projeto desenvolvido para praticar JavaScript, trabalhando com manipulação do DOM, eventos e armazenamento de dados.

A aplicação permite adicionar, concluir e excluir tarefas, mantendo os dados salvos mesmo após atualizar a página.

💻 Sobre o projeto

A proposta foi criar uma lista de tarefas simples e funcional, utilizando JavaScript para adicionar, concluir e excluir tarefas de forma dinâmica.

O projeto também utiliza o LocalStorage para manter as tarefas salvas no navegador, mesmo após atualizar a página.

Projeto desenvolvido para praticar e consolidar fundamentos de JavaScript e manipulação do DOM.
