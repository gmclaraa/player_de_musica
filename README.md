🎵 Music Player

Projeto desenvolvido para praticar JavaScript, trabalhando com manipulação do DOM, eventos e controle de áudio.

O player permite reproduzir e pausar músicas, navegar entre diferentes faixas, exibir informações da música atual e acompanhar sua duração e progresso em tempo real.

💻 Sobre o projeto

A proposta foi criar um player de música simples e funcional, utilizando JavaScript para controlar a reprodução dos áudios, atualizar as informações das faixas e acompanhar o progresso da música em tempo real.

O projeto também trabalha com a troca dinâmica de músicas, alterando título, artista, capa e duração conforme a faixa selecionada.

Projeto desenvolvido para praticar e consolidar fundamentos de JavaScript e manipulação do DOM.
